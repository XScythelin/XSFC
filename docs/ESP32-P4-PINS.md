# FireBeetle 2 ESP32-P4 V1.0: пины XSFC по умолчанию

Плата DFRobot DFR1172. Номера ниже — **GPIO чипа**, не порядковые номера
контактов гребёнки. Источник назначений: `lib/Xsfc/src/Target/TargetESP32p4.h`.
Сохранённые настройки имеют приоритет: обновление прошивки их не заменяет.

## ESC / моторы

| Мотор | Индекс в CLI | GPIO |
| --- | --- | --- |
| M1 | pin_output_0 | 33 |
| M2 | pin_output_1 | 49 |
| M3 | pin_output_2 | 50 |
| M4 | pin_output_3 | 52 |

Сигналы ESC подключаются к GPIO, сигнальная земля — к общей GND платы.
Силовое питание ESC не подключать к GPIO. Протокол выбирается отдельно.
Проверки нумерации, направления и работы выходов — только без пропеллеров.

GPIO48 исключён из defaults: пользователь подтвердил отказ сигнала на нём
и работу того же выхода после переноса на GPIO33. Причина отказа GPIO48
не установлена; это не доказательство общего ограничения всех ESP32-P4.

## UART

TX/RX указаны **со стороны контроллера**. Соединять крест-накрест:
TX приёмника → RX контроллера, RX приёмника → TX контроллера.

| UART аппаратный / Serial в коде | TX GPIO | RX GPIO | Функция по умолчанию |
| --- | --- | --- | --- |
| UART0 / Serial0 | 37 | 38 | MSP, 115200 |
| UART1 / Serial1 | 4 | 5 | MSP, 115200 |
| UART2 / Serial2 | 22 | 23 | Serial RX (приёмник) |
| UART3 / Serial3 | -1 | -1 | Отключён, пины не назначены |
| UART4 / Serial4 | -1 | -1 | Отключён, пины не назначены |

Индекс Serial в CLI начинается с 0; подписи UART в конфигураторе могут
начинаться с 1. Для приёмника ориентироваться на GPIO22/23 и Serial RX,
а не только на номер строки. Скорость приёмника определяется протоколом:
например, CRSF использует 420000, несмотря на базовое поле UART 115200.
Питание приёмника — по его спецификации; уровни сигналов GPIO — 3.3 В.

USB Serial/JTAG — отдельный MSP-порт через разъём программирования,
GPIO24/25; это не UART0 и не отдельный разъём USB OTG. USB-пины не занимать
другими устройствами. Встроенный C6 не используется.

## I2C

| Сигнал | GPIO | CLI |
| --- | --- | --- |
| SDA | 7 | pin_i2c_sda |
| SCL | 8 | pin_i2c_scl |

Общая GND, подтяжки SDA/SCL к 3.3 В. Рабочая скорость ограничена 400 кГц,
даже если сохранённая настройка выше. IMU/барометр могут делить шину при
разных адресах. Для ICM42688 см. [ICM42688.md](ICM42688.md),
для ICM20948 — [ICM20948.md](ICM20948.md).

## SPI

| Сигнал | GPIO | CLI |
| --- | --- | --- |
| SCK | 28 | pin_spi_0_sck |
| MOSI / SDI датчика | 30 | pin_spi_0_mosi |
| MISO / SDO датчика | 29 | pin_spi_0_miso |
| CS gyro | 32 | pin_spi_cs_0 |
| CS барометра | -1 (не назначен) | pin_spi_cs_1 |

GPIO33 раньше был CS барометра; теперь это M1. Для SPI-барометра нужно
отдельно назначить свободный, выведенный GPIO как CS, не пересекающийся
с моторами, UART и прочими устройствами. I2C-барометру CS не нужен.

## Другие назначения

| Назначение | GPIO |
| --- | --- |
| Вход PPM (не UART Serial RX) | 36 |
| Buzzer | 34 |
| Встроенный LED | 3 |
| Кнопка BOOT | 35 |
| ADC напряжения | 20 |
| ADC тока | 21 |

ADC требуют согласования уровней/делителей: не подключать аккумулятор
напрямую. Для внешнего зуммера может потребоваться транзисторный драйвер.
SD, микрофон, C6, камера и дисплей прошивкой не инициализируются; это не
означает, что все связанные с ними GPIO электрически свободны на плате.

## Уже сохранённая конфигурация

Если переходите со старых motor defaults и не используете SPI-барометр:

```text
set pin_spi_cs_1 = -1
set pin_output_0 = 33
set pin_output_1 = 49
set pin_output_2 = 50
set pin_output_3 = 52
save
```

Затем ручной Disconnect/Connect. Перед перепайкой отключить USB и аккумулятор.
Если SPI-барометр используется, сначала выбрать ему отдельный CS и перенести
провод: назначать один GPIO одновременно ESC и CS нельзя.

Проверить фактические назначения: `get pin_output`, `get pin_serial`,
`get pin_i2c`, `get pin_spi`. Общий сброс defaults для смены одного пина не нужен.
