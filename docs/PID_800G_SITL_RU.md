# Итоговый профиль PID для 800 г — SITL, 7 ноября 2026

## Статус и сборка

Это текущий выбранный профиль **симулятора**, а не проверенный на реальном
коптере тюн. Команды ниже позволяют установить те же значения на XSFC, но
успешные SITL-тесты не гарантируют устойчивость и безопасность реального полёта.
Физическая плата при подборе не подключалась для записи настроек.

Исходная сборка: Mark4 V2 5″, Gemfan Hurricane V2 51466,
XING-E Pro 2207 2450KV, B&C 4S 2200mAh; полётная масса примерно **800 г**.

| Ось | P | I | D | F |
|---|---:|---:|---:|---:|
| Roll | 65 | 65 | 38 | 45 |
| Pitch | 68 | 70 | 40 | 45 |
| Yaw | 200 | **5** | 0 | 0 |

F — параметр feedforward XSFC. Здесь зафиксированы только эти 12 значений:
рейты, фильтры, Angle/Level PID и регуляторы высоты этим документом не меняются.
Для идентичной реакции недостаточно одних PID: важны остальные настройки,
частоты циклов, реальная тяга, задержки моторов и инерция.

## Что проверено

В репозитории `XSFC-Simulation` профиль хранится в
`sitl/profiles/800g-yaw-release.txt` и выбран для интерактивного запуска.
Физика/обмен — 1 мс; production gyro loop 8 кГц и PID 4 кГц используют
удержанные измерения IMU с частотой обмена 1 кГц.

- Roll/pitch выбраны из четырёх вариантов: показатель отслеживания команд
  улучшился примерно на 28% в двух исходных сценариях. Это не универсальная
  оценка качества и не подтверждение всей области устойчивости.
- Yaw первоначально был 200/50/0/0. После полного стика и отпускания
  воспроизведён обратный разворот; I уменьшен до 5.
- В полноразмерном raw-IMU Webots-тесте в Acro пиковая обратная скорость
  уменьшилась с 0,680/0,680 рад/с (~39°/с) до 0,047/0,020 рад/с
  (~2,7/1,2°/с) в двух направлениях. Отскок уменьшен, не полностью устранён.
- Пиковая скорость самой прокрутки уменьшилась примерно на 6%.
- С yaw I=5 прошли `yaw-release`, `tuned-flight`, `receiver-long-tilt`,
  `raw-disturbed`, а после удаления дополнительного линейного демпфирования
  также `raw-drop` и барометрический `receiver-hold`.
- Повторный ARM и RangeHold проходили с прежним yaw I=50; результаты нельзя
  автоматически считать повторной проверкой нового I=5.

Ограничения: инерция 0,003/0,003/0,005 кг·м² и диагональ 225 мм приближённые;
модель моторов — 5 Н/мотор при 14,8 В, линейная тяга, задержка 25 мс.
Это не измеренная характеристика указанных моторов/пропеллеров. Реальная
вибрация, RPM-фильтрация и компенсация постоянного yaw-момента с I=5
не подтверждены. Симуляция работает медленнее реального времени; реалистичность
всей траектории падения пока не установлена.

## CLI XSFC: сохранить текущие настройки перед изменением

**Снять пропеллеры, оставить DISARM.** Сохранить вывод `dump` в локальный файл.
Не запускать `defaults`, стирание памяти или импорт чужого полного дампа.

```text
dump
```

CLI-имена проверены по `lib/Xsfc/src/Connect/Cli.cpp`. Это синтаксис XSFC,
не набор стандартных имён Betaflight. Значение передаётся после имени без `=`.

## CLI: установить тот же профиль

Следующий блок **изменяет настройки подключённой платы**. Он приведён для
ручного применения пользователем; агент эти команды на оборудовании не выполнял.
`save` сохраняет конфигурацию и перезагружает XSFC.

```text
set pid_roll_p 65
set pid_roll_i 65
set pid_roll_d 38
set pid_roll_f 45
set pid_pitch_p 68
set pid_pitch_i 70
set pid_pitch_d 40
set pid_pitch_f 45
set pid_yaw_p 200
set pid_yaw_i 5
set pid_yaw_d 0
set pid_yaw_f 0
save
```

Изменения не должны затронуть назначение пинов, калибровку, рейты, фильтры,
режимы, Blackbox, частоты циклов или параметры DShot. `save` сохраняет всю
текущую конфигурацию, включая любые другие ранее сделанные несохранённые изменения.

## Проверка после перезагрузки

Снова открыть CLI и проверить все значения:

```text
get pid_roll_p
get pid_roll_i
get pid_roll_d
get pid_roll_f
get pid_pitch_p
get pid_pitch_i
get pid_pitch_d
get pid_pitch_f
get pid_yaw_p
get pid_yaw_i
get pid_yaw_d
get pid_yaw_f
```

Не считать чтение значений разрешением на безопасный полёт. Для отката
установить прежние 12 значений из сохранённого собственного `dump`, затем `save`;
не восстанавливать пины/калибровку/всю память без необходимости.
