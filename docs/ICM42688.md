# ICM42688-P: I2C

При выключенном питании подключите CS/nCS к 3.3 В, SCL/SCLK к SCL,
SDA/SDI к SDA, GND к общей земле. AD0/SDO: GND выбирает адрес 0x68,
3.3 В — 0x69. Не оставляйте CS и AD0 плавающими. Учитывайте перемычки
и подтяжки конкретного модуля. Питание подавайте по его схеме; сигналы
и подтяжки I2C должны быть совместимы с 3.3 В, не 5 В.

Отключите прежний управляющий GPIO от CS перед подключением CS к питанию.
После изменения подключения полностью выключите/включите питание.

Драйвер автоматически проверяет 0x68 и 0x69, если выбран AUTO или I2C bus.
При необходимости принудительно выбрать I2C:

```text
set gyro_bus = I2C
set gyro_dev = ICM42688
save
```

SDA/SCL контроллера должны быть настроены на реально подключённые GPIO.
После save выполните ручной Disconnect/Connect. Проверьте logs, devinfo,
stats. Переключение CLI не заменяет аппаратную установку CS.

P4 сейчас ограничивает I2C 400 кГц и опрос gyro 2 кГц; ODR датчика 8 кГц.
По SPI остаются ODR 8 кГц и опрос 4 кГц. gyro_dlpf у этого драйвера пока
не настраивает аппаратные фильтры; фильтрация и PID в этой доработке не менялись.

Host C++ fake-bus тесты проверяют оба I2C-адреса, явный SPI CS,
неверный ID, ошибки записи и неполные чтения без повреждения вектора.
Реальные питание, разводка и стабильность обмена требуют проверки без пропеллеров.

## Аппаратная фильтрация accel (исправление после полёта 22:39)

ODR gyro/accel остаётся 8 кГц, combined read сохранён. Перед включением
датчика драйвер явно задаёт **только accel**:

- Bank2 `03/04/05 = 0A/19/A0`: включён AAF 213 Гц
  (DELT=5, DELTSQR=25, BITSHIFT=10).
- Bank0 `52[7:4]=7`: UI BW=ODR/40=200 Гц.
- Bank0 `53[4:3]=2`: UI-фильтр третьего порядка; DEC2/reserved сохранены.

Основание: TDK DS-000347 rev1.9 §5.3, §5.5, §14.40–14.41.
Прежний reset UI BW был ODR/4=2 кГц, тогда как host берёт accel500Гц.
Фильтрация до выборки уменьшает внеполосный сигнал; программный BIQUAD15
после выборки не может исправить уже возникший алиасинг. Это не доказательство,
что именно алиасинг вызвал наблюдавшиеся 3–6g в полёте, и не идеальный brick-wall
фильтр на250Гц. Механическая вибрация/насыщение/ошибки данных остаются возможны.

Запись и readback выполняются только при старте. При сбое инициализация
отклоняется; Bank0 восстанавливается также после ошибки Bank2. Gyro AAF/notch/UI,
PID, Mahony, калибровка и программный accel LPF не меняются. Дополнительных
операций в управляющем цикле нет. Host-тесты проверяют bank-aware readback,
отказы/потерянные записи, сохранение gyro nibble/DEC2 и combined read.
