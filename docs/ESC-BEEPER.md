# BEEPER через ESC (DShot beacon)

## Короткая стартовая мелодия Bluejay

RTTTL: два восходящих тона с короткой паузой («ти-тí»), номинально около
130 мс по длительностям нот при указанном темпе:

```text
bluejay:b=570,o=5,d=16:8e,p,8b
```

Мелодию нужно записать в настройках самих ESC средствами конфигуратора Bluejay.
Это замена startup melody, а не изменение звука DShot BEEP1: режим BEEPER
в XSFC продолжает использовать стандартную команду ESC.

## Режим BEEPER

### Влияние Bluejay beacon на телеметрию

В проверенных upstream-исходниках Bluejay (`src/Modules/DShot.asm`,
`dshot_cmd_beeps_check`) команды BEEP1–5 отключают interrupts ESC,
вызывают `beacon_beep`, затем `wait200ms` и только после этого включают
interrupts. Во время этого участка нормальная bidirectional DShot
телеметрия недоступна; возможна задержка реакции ESC на последующие команды.
Поэтому высокий error rate во время beacon не равнозначен ошибке RMT RX.
Точный процент зависит от версии ESC firmware, длительности звука и
интервала команд XSFC (500 мс); на пользовательской плате наблюдалось 62.5%.
Это не объясняет ошибки вне режима BEEPER.

Источник: https://github.com/bird-sanctuary/bluejay/blob/main/src/Modules/DShot.asm

Настройте AUX-диапазон BEEPER в Betaflight Configurator. При включении режима
XSFC отправляет BEEP1 (DShot command 1 с telemetry-request bit) на все
подключённые моторные выходы. Внешняя пищалка не требуется.

Поддерживаются DSHOT150/300/600 и ESC, реализующие стандартные DShot beep
commands. Это короткий повторяющийся тон ESC, не воспроизведение startup music.
PWM/OneShot/Multishot не поддерживают эту функцию. Отдельный зуммер GPIO34
продолжает работать независимо, если подключён.

Защиты: только disarm и остановленные моторные выходы, не ранее 3 секунд
uptime; команда раз в 500 мс (BEEP1 требует не менее 260 мс). Между командами
передаётся штатная остановка. Arming или ненулевой тестовый газ прекращает
новые beep-команды; уже начатый звук заканчивает сама прошивка ESC.
Во время ESC passthrough Mixer не должен использоваться: beacon не отправляет
прямые команды в обход штатного пути моторных выходов.

Проверка на плате обязательна без пропеллеров: BEEPER ON/OFF, отсутствие
вращения, приоритет тестового газа, unidirectional/bidirectional DShot.
Повторная startup-мелодия ESC после reset контроллера — отдельная проблема,
этой функцией она не исправляется. Непрерывный beep во время полёта не добавлен.
